## 2. Разработка мини-CRM на React (Vite) + Tailwind CSS
Создан современный одностраничный веб-приложение (SPA) со следующей структурой:
* **Стек**: React 18, Vite, Tailwind CSS.
* **Главный компонент (`src/App.jsx`)**:
  * **Экран авторизации (Supabase Auth)**: Форма входа и регистрации по Email и Паролю. Защищает рабочее пространство CRM (интерфейс доступен только авторизованным пользователям).
  * **Панель управления заявками**: Таблица, отображающая список клиентов из базы данных (Имя, Телефон, Статус).
  * **Интерактивные статусы**: Возможность изменять статус заявки (*«Новая» / «В работе» / «Завершена»*) прямо в таблице с мгновенным обновлением в базе данных.
  * **Модальное окно создания заявки**: Форма добавления нового клиента, которая отправляет данные в таблицу `clients` в Supabase и обновляет список на экране.

## Решение нюансов авторизации (`email rate limit exceeded`)
При первичной регистрации может возникать ошибка `email rate limit exceeded`. Это стандартное ограничение бесплатного тарифа Supabase Auth на отправку писем подтверждения. 
**Решение**: в панели Supabase перейдите в **Authentication ➔ Providers ➔ Email**, отключите параметр **Confirm email** (переведите в положение **OFF**) и нажмите **Save**.
